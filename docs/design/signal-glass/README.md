# VoiceIsolate Signal Glass

Light-model desk for one session, one braid, and four ribbons. This is a design page, not product code. Nothing here is loaded by `public/` or `src/`.

Open `index.html` in a browser. The contract is `signal-glass.json`.

| View | What it shows |
|---|---|
| Session | “Bring the voice forward.” Helix through a tilted lens into voice, music, room, and air. |
| Stems | Four buses plus Master pre-limiter. Faders do not re-run separation. Mute and solo change the sum. |
| Engineer | Instrument-white curve, cyan selection ring, remembered processing toggles, flat monitor. |
| Transport | Play is the cyan pill. Loop and Export stay glass. The mix is the same on every page. |

Load studio demo means four independent performances. Import audio means four filtered focus buses from a local file. Audio stays on the device. This page is not a neural split, and it does not describe the published VoiceIsolate Pro release.

Shots in `shots/` are desktop 1440 px and mobile 375 px checks of this page.

The older plates in [`../mockups/README.md`](../mockups/README.md) are a separate direction.
