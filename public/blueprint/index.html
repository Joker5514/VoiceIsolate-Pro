Architecture

Production architecture at a glance.

Current Stem-Split and Live-Mix browser architecture. Historical blueprint claims for deleted runtime paths are not shown here.

Public shell

public/ landing, Engineer Console, download, docs. Web, Android, and Desktop share public/app/.

Core

src/core/ pure primitives: config, STFT budget, model manifest, buffer pool. No DOM, no Web Audio.

Workers

src/workers/ MLWorker ONNX, diarization, spectral cleanup, encoder. Gate + De-Esser playback worklets only.

Pipeline

src/pipeline/ ingestion, PlaybackMixer Live-Mix graph, processing and export orchestrators.

Presentation

src/presentation/ sliders, speakers, export, visualizers. May import pipeline and core only.

Models

Same-origin /app/models/*.onnx. SHA-256 via ModelManifest.js. Default chain bsrnn_vocals.

Audio graph

Clean/noise stems → gains → EQ → master. Sliders drive AudioParams. Process-time controls snapshot on Process.

Deployment

Vercel public/ with COOP/COEP. Capacitor and Electron consume build/. No CDN runtime for ORT.

Current production shape

  • Static deployment source: public/.
  • Build step: validate, verify worklets, then copy src/ into public/src/.
  • Audio privacy: user audio stays local in the browser.
  • Model delivery: same-origin /app/models/*.onnx routes.
  • Engineer controls: SLIDER_REGISTRY currently exposes 67 sliders.
  • Playback worklets: GateProcessor.js and DeEsserProcessor.js.

Spectral rule

Compatible spectral-mask stages use one forward STFT, in-place mask application on the shared representation, and one inverse STFT per analyzed frame.

Deployment headers

Production keeps COOP same-origin and COEP require-corp for isolation-sensitive browser features. Worklet scripts are served with JavaScript MIME types and no-cache headers; WASM and ONNX assets have explicit MIME rules.
