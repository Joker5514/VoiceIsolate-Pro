Privacy-first local processing

Simple on the surface.
Strict underneath.

One forward STFT. In-place spectral work. One inverse STFT. Make the spectral invariant visible as the product’s technical trust story. Audio is decoded locally; batch ML never runs from a slider.

  1. Input

    Upload-only file pick. No microphone.

  2. Decode / resample

    Local decode to 48 kHz buffers.

  3. Stem separation

    Batch ONNX in a worker (BS-RNN default).

  4. Spectral processing

    Fused masks on one STFT representation.

  5. Reconstruction

    One inverse STFT. No extra phase passes.

  6. Live-Mix

    Zero-ML playback graph: gains, EQ, gate, de-esser.

  7. Export

    Local encode. Optional user-initiated Drive save.

Why one spectral pass matters

Fewer transforms = fewer artifacts.

Compatible spectral operations share the same representation instead of repeatedly rebuilding the signal. Live-Mix never starts inference.
