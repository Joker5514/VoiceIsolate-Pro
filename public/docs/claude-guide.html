VoiceIsolate Pro Contributor Guide

This served guide mirrors the current production architecture. The repository source of truth for contributors is CLAUDE.md; this page exists so deployed documentation does not point agents or users toward removed runtime paths.

Current Runtime

Vercel serves public/. The build validates the repository and copies src/ to public/src/ before deployment. Root-level source copies are not production authority unless the build proves they are served.

Hard Rules

  • Do not add live microphone ingestion to the production browser runtime.
  • Do not upload user audio or run user audio through a remote inference endpoint.
  • Do not load ONNX Runtime, worklets, workers, or model code from public CDNs.
  • Do not block or run model inference inside an AudioWorklet render callback.
  • Do not restore deleted legacy auth, licensing, or audio-pipeline monoliths.

Spectral Invariant

one forward STFT
compatible spectral masks operate on the shared representation
one inverse STFT

The active ML worker uses a fused spectral-mask path for compatible mask models. Any future DSP stage that needs spectral data must share that representation instead of reconstructing and analyzing the same frame again.

Local Model Delivery

Models are requested from same-origin /app/models/*.onnx URLs. Vercel rewrites those paths to its Blob backend, while browser policy still sees a same-origin model route. Hash verification is controlled by src/core/ModelManifest.js.

Build And Deploy

pnpm install
pnpm run validate
pnpm run build
pnpm test -- --runInBand

Vercel uses node scripts/vercel-build.js and bash scripts/vercel-install.sh. The install hook reads the pinned pnpm version from package.json#packageManager.

Headers

Production must keep Cross-Origin-Opener-Policy: same-origin and Cross-Origin-Embedder-Policy: require-corp so isolation-sensitive browser features remain available.
