# .Jules (DEPRECATED)

This directory is a duplicate of `.jules/` created by a macOS case-insensitivity
artifact. On case-sensitive filesystems (Linux, Docker, Vercel), both `.Jules/`
and `.jules/` exist as separate directories.

**The canonical Jules configuration directory is `.jules/` (lowercase).**

This directory (`.Jules/`) should be considered empty and will be removed in a
future cleanup commit. Do not add files here.

See `.jules/` for active Jules agent configuration.
